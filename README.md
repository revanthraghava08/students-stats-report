# 📊 Students Performance — Statistical Analysis

Statistical analysis of 1000 students' exam scores using Python.

## Questions Answered
1. Are score distributions normal? (Shapiro-Wilk test)
2. How strongly do subjects correlate? (Pearson correlation)
3. Which students are outliers? (Z-score analysis)
4. Does test prep improve math scores? (t-test, p=1.54e-08)
5. Do reading scores differ by gender? (t-test, p=4.68e-15)

## Tools
Python · pandas · NumPy · SciPy · Matplotlib · Seaborn

## Key Findings
- Reading–Writing correlation: 0.955 (strongest)
- Test prep adds ~5.6 points to math scores (statistically significant)
- Female students score 7.14 points higher in reading (significant, not causal)
